# solarnebulae.com

The solarnebulae.com home page, served by GitHub Pages. Pulse's own pages are on
pulse.solarnebulae.com (the pulse-redirect repo).

`app-ads.txt` has to be here at the root domain: AdMob checks the root of the developer website on
the Play listing, even when that website is a subdomain. Keep it the same as the copy in pulse-redirect.
